# Changelog

## 1.0.0 — Portfolio release

- Complete the four-phase single-user SQL Playground MVP.
- Add Instagram, Bookstore, and blank starting datasets with working examples.
- Add JSON workspace backups/import and CSV result downloads.
- Preserve drafts during immediate workspace switching and creation.

- Add release tests, deployment build output, CI artifacts, architecture/schema docs,
  metadata, favicon, keyboard navigation, mobile schema visibility, and local fonts.
- Preserve Phase 1 Python engine and Phase 3 IndexedDB record compatibility.
